# Stage 12 handoff and acceptance

4 October 2026. The [release acceptance record](release-acceptance.md) covers every AC-01–12 criterion with executed evidence or an explicit limitation. [Release notes](release-notes-1.0.0.md), [compatibility policy](compatibility.md), [client integration](client-integration.md), [deployment/runbook](deployment.md), versioned schemas/OpenAPI/fixtures and a SHA-256 contract manifest are published in this repository. A reproducible ZIP can be generated without any native application or real account data. Running OpenAPI comparison and browser acceptance are added to CI.

Automated suites cover schema/domain/API/security rules, cross-language fixtures, mocked Drive errors and races, metadata preservation, photos/recovery, search, labels/strict scanning and optional tag workflows. Twelve compiled browser workflows pass across real headless Chrome, Playwright Firefox and Chrome mobile-layout emulation, using synthetic Google responses. A local HTTPS/non-root/read-only container run and token-free contract checks pass. Contract package reproducibility/hash verification is automated. See the acceptance record for repeatable commands and precise live/device boundaries.

Real Drive evidence now includes ten passed single-account UI workflow checkpoints on the updated localhost deployment; see the [deployment/full-test record](deployment-test-2026-10-04.md). No production mutations were enabled. Full real writable workflows, independent concurrent writers, final-policy/two-account Google lifecycle, native Drive search, public-domain operator setup, physical Chrome Android/Edge and NFC reference tags remain pending. The project is a read-capable 1.0.0 release candidate with explicit write gates, not an accepted writable production release. Native Android implementation/hardware acceptance belongs to the separate project.

Final automated verification: 277 frontend tests and 114 Python tests (116 contract subtests) passed, plus 12 browser workflows. ESLint/Prettier, TypeScript, Ruff/format, mypy, contract/prototype checks, generated-validator freshness, OpenAPI export and contract-archive checks passed. Existing Starlette/httpx deprecation and Vite main-chunk warnings remain; the main bundle is approximately 600 kB minified/175 kB gzip, with a separate lazily loaded QR decoder.
